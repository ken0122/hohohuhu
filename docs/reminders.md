# 一张小纸条：实现约定

基于 2026-09-02 的本地工作区更新；远端 `origin/main` 为 `9380589`，本地已包含其全部提交。保留原有角色功能改动，不把同步理解为推送。

## 与早期方案的差异

- 使用用户配置的对话模型、Anthropic Messages 兼容 HTTPS 接口和当前角色人格，不固定 DeepSeek，不发送 thinking / effort 参数。
- 单次请求要求紧凑 JSON 意图，不要求网关支持 tools / tool_choice；主进程严格解析，未遵循格式时不创建提醒、不回退为“已记住”。输出预算仍为 160 token。
- 复用现有主题和七种界面语言，纸条内容保持用户原文。提醒与角色无关，换角色不清除。

## 交互

聊天快捷键和菜单入口不变。模型可返回普通聊天、创建、补充信息、查看、取消；只允许一条一次性提醒。相对时间以消息提交时间为起点，明确时刻由模型提供带 UTC 偏移的日期，主进程校验并固定为绝对到期时间。时间不明确、过去时间、周期性和多个事项要求澄清。每次聊天请求会携带当前纸条、内存中的结构化草稿及提交时间和时区，以识别相关意图；不传聊天历史。

新提醒只有保存成功才确认。已有纸条时展示新旧事项和时间，选择保留或替换；关闭保留旧纸条。“已记一条”入口可离线查看与取消。到期后提供“收到啦”、关闭和继续聊天，没有稍后按钮；继续聊天也视为收起本次到期展示。“收到啦”删除纸条，收起不删除且不重复弹出。

正常 Pet / Dodge 状态自动展开相同尺寸气泡，不抢焦点；已有聊天、拖拽、方向键控制或菜单交互时暂缓。聊天期间标记到期而不覆盖草稿；关闭聊天后展示。手动隐藏或吃豆豆中使用无正文的系统通知兜底，不唤醒隐藏宠物、不切换模式。恢复后仍可查看到期纸条。系统权限、专注模式可能阻止通知展示，应用不声称已送达。

## 实现边界

- 主进程的纸条服务管理单条状态、替换提案、请求版本和送达去重；renderer 仅获得展示数据与有限操作。
- `reminder-v1.enc` 位于 userData，以 safeStorage 加密并原子替换，不含密钥或聊天历史。存储失败不确认成功；损坏文件不自动覆盖，用户可明确清除。
- 一秒独立计时检查，启动/唤醒/解锁核对到期；应用关闭、休眠或关机期间不能准时提醒，恢复后补提醒。定时器不依赖 renderer 帧率。
- 创建、替换、取消与收下以版本校验防止旧请求覆盖新状态。退出动画、手动隐藏和原有窗口恢复逻辑继续拥有各自状态。
- 272×242 逻辑像素窗口、248×140 气泡不变。到期使用短暂轻弹与三颗星星，随后静态停留；浅深色跟随主题，减少动态效果关闭所有新增装饰运动。

## 验证与限制

单测使用假时钟、虚构凭据、mock HTTP 与加密替身，覆盖解析、单条容量、确认替换、版本冲突、持久化、过期恢复和送达去重。桌面测试使用隔离 userData 与 mock 模型，通过真实气泡提交、按钮和原生窗口验证链路，并捕获外观截图。

真实模型意图准确率与系统通知最终展示需另行实际验收；自动测试不请求真实模型，不把提示词断言当作语义准确率证据。此功能不是关键事务或安全提醒服务。
